Rashko site photo folders

Add your own photos here using these filenames:
- hero.jpg: homepage hero image
- about.jpg: About page dining-room/story image
- gallery/1.jpg through gallery/9.jpg: gallery photos (the homepage uses 1.jpg through 4.jpg)
- dishes/<dish-slug>.jpg: dish cards and dish detail pages

Dish filenames must match the dish URL slug. For example:
- /menu/mandi-chicken -> dishes/mandi-chicken.jpg
- /menu/bbq-chicken-and-rice -> dishes/bbq-chicken-and-rice.jpg

JPG filenames are expected by the current code. If a file is absent or fails to load, the existing green placeholder remains visible.
